# Step 7 – Microsoft 365 Copilot: known limitation (skipped)

[⬅ Previous: Test in Teams](06-test-in-teams.md) | [Next: Clean up ➡](08-cleanup-and-troubleshooting.md)

The same publish also makes the agent available in **Microsoft 365 Copilot** (called with `@ntcorp-policy-agent`). I **skipped** this test.

**Why:** using agents inside Microsoft 365 Copilot requires a **Microsoft 365 Copilot licence**, and the Microsoft 365 Business trial doesn't include one. Buying a licence just for a lab wasn't worth the cost.

**Impact:** none on the main goal. Teams works, and in a company that already has Copilot licences, the same published agent would appear in Copilot with no extra build work.
